# Развёртывание Figures

Приложение полностью в Docker: **frontend (nginx)** отдаёт сайт на порту `8080` и
проксирует `/api` в **backend (FastAPI)**. Публичный доступ по IP работает
«из коробки» — фронт обращается к API по относительному пути `/api`, домен не нужен.

---

## 1. Первый запуск на сервере

Нужны установленные **Docker** и **Docker Compose** (плагин `docker compose`).

```bash
# 1. Клонировать репозиторий (замените URL на свой)
git clone https://github.com/<ВАШ_ЛОГИН>/<ВАШ_РЕПО>.git figures
cd figures

# 2. Собрать и запустить
make up            # то же самое: docker compose up -d --build

# 3. Проверить, что поднялось
make ps
```

Открыть в браузере: **http://<IP-сервера>:8080**

> Порт `8080` должен быть открыт в фаерволе/группе безопасности сервера.
> Пример для ufw: `sudo ufw allow 8080/tcp`

---

## 2. Обновление после изменений в GitHub

Когда вы запушили новую версию в GitHub, на сервере:

```bash
cd figures
make deploy        # git pull + пересборка + перезапуск
```

Или вручную:

```bash
git pull --ff-only
docker compose up -d --build
```

---

## 3. Полезные команды (Makefile)

```bash
make up        # запустить (собрать + поднять в фоне)
make down      # остановить
make restart   # перезапустить
make logs      # смотреть логи (Ctrl+C — выход)
make ps        # статус контейнеров
make clean     # остановить и удалить тома (загруженные файлы)
make rebuild   # пересборка без кеша
make help      # список всех команд
```

---

## 4. Безопасность на публичном сервере (опционально)

По умолчанию наружу открыты два порта: `8080` (сайт) и `8000` (API/докуменация FastAPI).
Для публичного доступа обычно достаточно только `8080`. Чтобы закрыть `8000`,
уберите проброс порта у сервиса `backend` в `docker-compose.yml`:

```yaml
  backend:
    build: ./backend
    # ports:                 # ← закомментируйте эти две строки
    #   - "8000:8000"
    ...
```

Внутри Docker-сети backend всё равно доступен фронту по имени `backend:8000` —
проксирование `/api` продолжит работать, а прямой доступ к API снаружи закроется.

---

## 5. Данные

Загруженные пользователями файлы хранятся во временном Docker-томе `uploads`
(внутри контейнера `/data/uploads`) и периодически чистятся. Исходные файлы
на диске сервера не меняются. Ваши примерные таблицы можно держать в папке `Data/`.
